# Roblox + Claude

Claude kann damit direkt in Roblox Studio bauen und coden.

## Einmalig einrichten

1. **Roblox Studio** öffnen und das **MCP-Plugin** aktivieren.
2. Dieses Repo herunterladen: auf GitHub **Code → Download ZIP** klicken und entpacken.
3. Im entpackten Ordner **`START.bat` doppelklicken**.
   - Claude Code wird automatisch installiert (falls nötig) und gestartet.
   - Beim ersten Start fragt Claude, ob `Roblox_Studio` verwendet werden darf → **Ja**.

## Jedes Mal danach

1. Roblox Studio öffnen.
2. `START.bat` doppelklicken.
3. Claude sagen, was du willst, z. B.:
   - „Bau mir einen Obby mit 10 Stufen“
   - „Mach ein Coin-System mit Leaderboard“
   - „Füge einen Shop hinzu“

## Probleme?

| Meldung | Lösung |
|---|---|
| `mcp.bat wurde nicht gefunden` | Roblox Studio öffnen, MCP-Plugin aktivieren, neu starten |
| `Roblox_Studio` nicht verbunden (bei `/mcp`) | Roblox Studio muss **offen** sein, dann Claude neu starten |
| Claude-Befehl nicht gefunden | PC neu starten und `START.bat` erneut ausführen |
